# Get help with RelayCrew

Start with the [README](README.md), [team operations guide](docs/teams.md), and [account setup guide](docs/accounts.md).

Use [Discussions](https://github.com/sep1ol/relaycrew/discussions) for setup questions, troubleshooting, provider interoperability questions, and early ideas. Include the RelayCrew version or commit, your Node.js version, and the relevant client version. Describe your setup with synthetic examples.

Use [Issues](https://github.com/sep1ol/relaycrew/issues) for reproducible bugs and concrete feature requests. Search existing reports first. For a bug, include the steps to reproduce, expected behavior, actual behavior, and relevant versions.

Report credential exposure, cross-member access, authorization bypasses, and other vulnerabilities through [private security reporting](https://github.com/sep1ol/relaycrew/security/advisories/new). Follow [SECURITY.md](SECURITY.md) if that channel is unavailable. Keep vulnerability details out of public issues and discussions.

Never share real credentials, configuration files, private account details, prompts, request logs, or certificate private keys in support requests. Use synthetic data and sanitized error messages.

To contribute a fix or review a pull request, follow [CONTRIBUTING.md](CONTRIBUTING.md). This community fork is maintained at `sep1ol/relaycrew`; open its support threads and pull requests there.
